## 工作包 B：从技术原型到连续监测

### DEV-03 长期采集和有界统计

当前约束：`Capture::start`限制600秒；`Statistics`保留整段样本、每链200万条，快照排序/扫描成本随会话增长；桶统计也为当前有界会话设计。不要只删时长校验就声称无限会话。

- [ ] 定义长时会话的内存预算、精度及low算法；先测量当前开销，不编造预算值。
- [ ] 滚动窗口有界、会话聚合不无限保存原始帧；low精确/近似策略公开并测试。
- [ ] 采集器连续运行、目标退出/切换、取消/清理、未知权限的行为保持一致。
- [ ] 长暂停、零帧、交换链变化、异常时间戳、丢失事件/采样上限有明确状态。
- [ ] 做超600秒和高帧率回归，确认内存/CPU不持续增长。

验收：长时不会无声停止/永久拒收；内存有界；正常退出无本程序ETW遗留；统计不跨目标污染。

### DEV-04 窗口与历史统计完整化

- [ ] 配置滚动窗口秒数与默认30秒，配置升级兼容旧版本。
- [ ] 清楚选择/展示滚动与会话两套指标，不混用标签。
- [ ] 用固定时间采样/聚合历史，显示时间跨度/量程；处理空洞和过期。
- [ ] min/max仍按完整1秒桶，low定义与样本门槛保留；对浮点边界补测试。
- [ ] 稳定主交换链选择，必要时提供用户可理解的纠正入口。

验收：不同HUD刷新率得到同一统计；窗口配置/会话重置不混数据；图表横轴语义真实。
